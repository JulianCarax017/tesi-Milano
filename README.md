# tesi-Milano

Research code and documentation for a thesis on adaptive routing across frozen BERT experts for sentiment classification (SST) and natural language inference (MNLI).

## Project

The experimental model learns to select expert layers or skip computation at each encoder depth. The study examines classification quality, computational cost, expert reuse, and the role of a merged first encoder layer.

The experimental workflow covers dataset preprocessing, expert training, baseline evaluation, routed-model training, and routing-policy analysis.

## Repository status

This repository is being prepared. Experimental notebooks, environment details, and verified results will be added after review. This initial version does not contain executable experiments or final thesis results.
